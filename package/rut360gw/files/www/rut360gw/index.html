USSD session

		
Send a code such as *600#, then answer the operator menus (0, 6, 00…).
			Refused during a GSM call. On some networks a USSD request interrupts mobile data for up to a minute.

		

		

		

			

			

		

		

			
			
		

		

	


	
	

		
Setup

		
The gateway can work with a remote SIP server (Asterisk, FreePBX…), with a softphone on the LAN (Settings tab), or both. If the server is reached through a VPN, set the VPN up in RutOS (Services › VPN); the gateway does not create tunnels.
